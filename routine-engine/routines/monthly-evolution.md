# Monthly Evolution Routine

**Schedule**: 17:00 first day of month (17:00 UTC)
**Phase**: 1-5 (Inspect + Diagnose + Propose + Execute + Validate)
**Priority**: High
**Evidence Required**: Evolution tracking + knowledge base updates

## Overview

Monthly evolution routine drives continuous improvement through team composition evolution, skill matrix updates, and knowledge base refinement. It focuses on strategic evolution rather than day-to-day maintenance.

## Execution Flow

### Phase 1: Inspect (14:00-14:15)

**Goal**: Comprehensive evolution assessment

1. **Evidence Collection**
   - Historical performance data (5 minutes)
   - Skill evolution metrics (10 minutes)
   - Team effectiveness analysis (10 minutes)
   - Knowledge base coverage assessment (5 minutes)

2. **Evolution Metrics Analysis**
   - Skill development progress
   - Team effectiveness trends
   - Knowledge completeness
   - Evolution readiness assessment

### Phase 2: Diagnose (14:15-14:45)

**Goal**: Strategic evolution opportunities identification

1. **Evolution Gap Analysis**
   - Skills vs. project complexity gaps
   - Knowledge coverage deficiencies
   - Team effectiveness thresholds
   - Evolution velocity assessment

2. **Evolution Recommendations**
   - Team composition evolution strategies
   - Skill development priorities
   - Knowledge base improvement initiatives
   - Process evolution suggestions

### Phase 3: Propose (14:45-15:00)

**Goal**: Evolution plan creation and validation

1. **Evolution Migration Planning**
   - Phased evolution approach
   - Resource allocation for evolution
   - Timeline and dependency planning
   - Risk mitigation strategies

2. **Evolution Proposal Validation**
   - Feasibility assessment
   - Impact analysis
   - Resource requirement validation
   - Success criteria definition

### Phase 4: Execute (15:00-15:30)

**Goal**: Implementation of evolution changes

1. **Evolution Implementation**
   - Team composition adjustments
   - Skill matrix updates
   - Persona attribute evolution
   - Knowledge base enhancements

2. **Evolution Validation**
   - Evolution effectiveness testing
   - Impact measurement
   - Rollback preparation

### Phase 5: Validate (15:30-16:00)

**Goal**: Post-evolution assessment and optimization

1. **Evolution Effectiveness Analysis**
   - Metrics improvement assessment
   - Team effectiveness evaluation
   - Knowledge base completeness check

2. **Optimization Recommendations**
   - Evolution process improvements
   - Metric refinement
   - Future evolution planning

## Troubleshooting

### Evolution Execution Issues
- **Team Resistance**: Implement gradual changes, demonstrate value
- **Skill Gaps**: Provide development resources, schedule training
- **Knowledge Incomplete**: Focus on critical topics first, phased approach

### Evolution Planning Challenges
- **Resource Constraints**: Prioritize high-impact changes
- **Timeline Conflicts**: Implement staggered approach
- **Measurement Difficulties**: Use proxy metrics, qualitative assessments
